# Superstore Sales Dashboard

## Project Overview
This project was completed as part of the SkillCraft Technology Data Analytics Internship.

The dashboard was created using Microsoft Excel and the Superstore Sales dataset to analyze sales performance across categories, regions, and time periods.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting

## Dashboard Features
- Sales by Category Analysis
- Sales by Region Analysis
- Sales Trend Over Time
- High and Low Performing Sub-Categories

## Key Insights
- Technology was the highest-performing category.
- West was the highest-performing region.
- November 2018 recorded the highest sales.
- Phones, Chairs, and Storage were the top-performing sub-categories.
